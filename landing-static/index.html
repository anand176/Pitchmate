Integrations & stack

Wired into where you already work

Integrations

Notion for pipeline sync, Google Calendar for follow-ups and Drive for documents, ElevenLabs voice for spoken Call Practice, plus Figma and Draw.io over MCP. Each one is optional — leave the credentials blank and the rest of the product runs unchanged.

Built on

FastAPI and LangChain-LangGraph driving Gemini 2.5 Flash, Postgres for self-hosted JWT auth and chat session persistence, Pinecone for knowledge-base vector search, and a React + Vite front end. Signup, login and logout are fully self-hosted — no external auth provider.
